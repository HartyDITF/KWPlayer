# KW Player — дорожная карта реализации

Последнее обновление: 26 ноября 2026 г.

- Исправлено сохранение акцентного цвета: Compose `Color.value` — упакованное 64-битное значение, его нельзя преобразовывать в ARGB через `toInt()`; используется `toArgb()`, чтобы цвет не становился прозрачным. Акцент теперь корректно сохраняется и применяется после перезапуска и смены скина.
- Настройки видеоплеера переделаны в компактную нижнюю панель в стиле YouTube: горизонтальные чипы выбора формата, цвета полей и шага перемотки, компактные переключатели и поле HEX только для своего цвета. Проверка CI и устройств ожидается.

- Снимок кадра: исправлен импорт `PixelCopy`; GitHub Actions #154 успешно собрала debug APK (17 268 403 байта). Проверка сохранения PNG на устройствах ещё ожидается.
- Задержка субтитров пока отложена: `MediaItem.SubtitleConfiguration.timeOffsetUs` добавлен в Media3 1.12.0, а проект использует стабильную 1.11.1. Не обновлять Media3 до предварительной версии только ради этой функции.

- Добавлена настройка шага перемотки 5 / 10 / 15 / 30 секунд. Значение сохраняется в DataStore и применяется к двойному касанию слева/справа и центральным кнопкам перемотки. CI №146 успешно собрала debug APK; тестирование на устройствах ожидается.
- Добавлен повтор A–B: пользователь задаёт начальную и конечную точки, плеер циклически возвращается к началу диапазона. Повтор сбрасывается при смене видео; контроль позиции выполняется только при активном воспроизведении. CI №150 успешно собрала debug APK; проверка на устройствах ожидается.
- Добавлен снимок текущего видеокадра только на паузе: кадр копируется с SurfaceView через PixelCopy и сохраняется в Pictures/KW Player на Android 10+, на Android 8–9 предлагается сохранить PNG через системный выбор файла. CI и проверка на устройствах ожидаются.

- Добавлено сохранение пользовательских настроек видеоплеера: режим масштабирования, цвет боковых полей и запрет выключения экрана. Сборка и проверка на устройствах ещё ожидаются.
- Добавлен отдельный режим кадра 4:3: видеоповерхность центрируется в области 4:3, а само видео сохраняет пропорции через FIT. Настройка сохраняется в DataStore.
- Добавлены локальные закладки видеоплеера: сохранение текущего времени, переход к сохранённому моменту и удаление закладки. Записи хранятся отдельно для URI каждого видео.

- Переключение отображения видеотеки «Главная / Список / Сетка» сохраняется в DataStore и восстанавливается при следующем запуске. Проверка CI и устройств ещё требуется.

- Исправления видеоплеера: полноэкранный диалог использует всю область экрана без системного вписывания; зоны касаний объединены в один слой, чтобы обработчики жестов не перекрывали друг друга. Исправлена ошибка типа в PlaybackService, блокировавшая CI. Проверка на POCO X8 Pro Max ещё требуется.

> Статус отмечается по фактическому коду в репозитории. Успешная CI-сборка подтверждает компиляцию, но не заменяет проверку на физических устройствах. Пункт не считается завершённым, пока его критерии не выполнены.


- Исправлена ошибка CI №163: после замены настроек видеоплеера на `ModalBottomSheet` отсутствовала закрывающая скобка `VideoPlayerScreen`; из-за этого вспомогательные функции снимка кадра, закладок и шкалы времени компилятор воспринимал как локальные. Скобка восстановлена в коммите `289559b`; повторная сборка ожидается.


- Подготовка следующего выпуска: версия приложения повышена до `0.3.8` (`versionCode = 9`) после релиза `v0.3.7`. Debug CI №165 прошла успешно на предыдущем коммите; после изменения версии требуется повторная CI-проверка перед созданием тега и подписанного релиза.

## Правила ведения дорожной карты

1. Обновлять этот файл после каждого завершённого этапа и существенного исправления.
2. Ставить `[x]` только за реально реализованный код; отдельной строкой указывать, прошла ли CI и проверено ли на устройстве.
3. Не выдавать макет интерфейса за работающую функцию.
4. Не считать успешную компиляцию доказательством стабильности на телефоне.
5. Сверяться с `KW_Player_prompt.md` перед каждым этапом (файл с таким написанием находится в корне репозитория).
